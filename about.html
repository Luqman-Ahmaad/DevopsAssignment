About TaskFlow

What is TaskFlow?

TaskFlow is a lightweight, browser-based task management application designed to help you organize your daily tasks efficiently. It stores all your tasks locally in your browser's storage, so no internet connection is required after the page loads.

Purpose

The purpose of TaskFlow is to provide a simple, clean, and intuitive interface for managing personal tasks. Whether you're a student, professional, or homemaker, TaskFlow helps you keep track of what you need to do, what's pending, and what's already completed.

How to Use TaskFlow

1. Dashboard (Home)

Get an overview of your tasks with summary counters: total, pending, and completed tasks. Quickly navigate to other pages using the navigation bar.

2. Add Task

Fill in the form with a task title, description, due date, and priority (High/Medium/Low). Click submit to save the task to your local storage.

3. Task List

View all your tasks in a sortable table. Use the filter buttons (All / Pending / Completed) to focus on what matters most.

4. Task Detail

Click on any task to see its full details. From here, you can mark a task as complete or delete it permanently.

5. About (this page)

Learn more about the application and how to use it.

  • JavaScript – Interactivity and local storage
